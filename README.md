# Chainsaw Sharpening Reference

Mobile-first, installable iPhone web app. Select pitch and gauge, then add manufacturer-verified chain models and sharpening measurements. Data is saved locally; export/import JSON backups.

## Deploy on GitHub Pages
1. Create a public GitHub repository, e.g. `chainsaw-reference`.
2. Upload `index.html`, `manifest.webmanifest`, `icon.svg`, and `sw.js` to the repository root.
3. Go to **Settings → Pages → Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. Open the GitHub Pages URL in Safari on iPhone; choose **Share → Add to Home Screen**.

## Important
The supplied scanned chart has not been reliably transcribed. No unverified filing dimensions are preloaded. Add exact specifications from the chain manufacturer's documentation. Pitch and gauge do not uniquely identify filing angles or file diameter.
